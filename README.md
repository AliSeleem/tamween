# تموين — نظام إدارة وتشغيل محل التموين

تطبيق سطح مكتب (ويندوز أولًا) لمحل التموين، مبني على [وثيقة المتطلبات](docs/tamween_prd.md). يعمل بدون إنترنت، وكل البيانات في ملف واحد على الجهاز.

## ما يغطيه الإصدار الحالي

| الشاشة | ماذا تفعل |
|---|---|
| لوحة المتابعة | إجابات أسئلة §25: عدد البطاقات والأفراد، المضروب والمستلم، إجمالي الضرب، فروق التسوية، أرصدة الأصناف، والتنبيهات. |
| الاستلام الفعلي | بحث بالرقم أو الاسم، عرض المتبقي للمواطن، تسجيل استلام كامل أو جزئي، أو صرف مقدم على الشهر التالي. |
| الضرب ودفعات التسوية | دفعات بحدود قابلة للتعديل (افتراضيًا 47,100 ج / 954 سكر / 876 زيت)، تسجيل ضرب البطاقة، حساب فرق الزيادة، ومنع تجاوز الحدود. |
| متابعة البطاقات | الشاشة المقترحة في §14 بكل الفلاتر: ضُربت ولم تستلم، استلمت ولم تُضرب، استلام جزئي، لها رصيد… |
| البطاقات | إضافة وتعديل وبحث، مع كشف حساب لكل بطاقة: دفتر الحقوق، الضرب، الاستلام، الحركات، وسجل التعديلات. |
| المخزون | أول المدة، الوارد، المرتجع، التالف، الجرد، والعكس الموثق. الصرف للمواطن يخصم تلقائيًا. |
| استيراد Excel | ملف xlsx أو csv بأي ورقة، يكتشف صف العناوين تلقائيًا (حتى لو فوقه اسم المكتب والتاجر) ويربط الأعمدة بالأسماء العربية. رقم البطاقة اختياري: بدونه تُعرف البطاقة بالاسم مع الرقم السري. مراجعة التكرار والنواقص قبل الاعتماد. |
| الإعدادات | فتح وإغلاق الشهور، قواعد الاستحقاق وقيمة البطاقة حسب عدد الأفراد، أسعار الأصناف، الأصناف، المستخدمون، النسخ الاحتياطي. |
| سجل العمليات | كل عملية بمن قام بها ومتى وتفاصيلها. |

### القواعد المطبقة من الوثيقة
- **الضرب والاستلام منفصلان** (§8، §21): لكل بطاقة حالة POS وحالة استلام مستقلتان، ويرتبطان تلقائيًا في نفس الشهر مهما كان الترتيب.
- **لقطة شهرية لعدد الأفراد** (§4): فتح الشهر يجمّد عدد الأفراد؛ تعديل البطاقة أثناء الشهر يظهر من الشهر التالي.
- **دفتر حقوق المواطن** (§9): المتبقي = مجموع الحركات (استحقاق، حق من الضرب، استلام، مرحل). لا يُعدّل رصيد يدويًا.
- **المرحل والمقدم** (§10): إغلاق الشهر يرحّل المتبقي للأصناف المسموح بترحيلها، وينتهي لغيرها؛ المقدم يُخصم من الشهر التالي.
- **فرق الزيادة** (§6): ما زاد عن قيمة البطاقة يُسجل كفرق تسوية مطلوب سداده للمؤسسة، ولا يُعتبر حقًا للمواطن ولا إيرادًا.
- **لا حذف** (§18): الإلغاء يكتب حركة عكسية بالسبب واسم المستخدم. الإلغاء وفتح وإغلاق الشهور وتعديل القواعد للمدير فقط.

## التشغيل لأول مرة
1. ثبّت البرنامج وافتحه، وادخل بـ `admin` / `admin` (سيُطلب تغيير كلمة المرور).
2. من **الإعدادات ← الشهور** افتح الشهر الحالي.
3. من **الإعدادات ← الاستحقاق والأسعار** أدخل قيمة البطاقة لكل عدد أفراد وأسعار الأصناف.
4. استورد البطاقات من **استيراد Excel**، ثم أدخل **رصيد أول المدة** من شاشة المخزون.

للتجربة: على قاعدة بيانات فارغة يظهر زر **تحميل بيانات تجريبية** في لوحة المتابعة (وفي الإعدادات ← عام). يضيف 12 بطاقة وشهرًا مفتوحًا وأسعارًا ودفعة ضرب وعمليات استلام تغطي كل حالات المتابعة.

## للمطورين

Electron + React + TypeScript، وقاعدة SQLite عبر `node:sqlite` المدمجة في Electron (بدون مكتبات native).

```bash
npm install
npm run dev        # تشغيل للتطوير
npm test           # اختبارات السيناريوهات (تحتاج Node 22.5 أو أحدث)
npm run typecheck
npm run dist:win   # مثبّت ويندوز في release/
```

- `src/main/services/` منطق النظام كله (يعمل ويُختبر بدون Electron).
- `src/main/db/schema.ts` الجداول؛ أي تغيير يُضاف كـ migration جديدة في آخر القائمة.
- `src/shared/api.ts` عقد الاتصال بين الواجهة والمنطق.
- `src/renderer/` الواجهة العربية.
- قاعدة البيانات في `%APPDATA%/Tamween/tamween.sqlite` على ويندوز (أو المسار في `TAMWEEN_DB`).
